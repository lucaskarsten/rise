Rise

A desktop companion that helps League of Legends players improve, game by game. It rewards playing well, not only winning.

Before the game

A plan for your lane

Picks, runes, items and summoner spells from aggregated winrates for your elo, role and matchup, applied straight to the client. Hover anything for its full in-game description: stats, effects, cooldown, cost, price and recipe.

In game

What to do right now

A small overlay with the current lane phase and short, timely reminders: objectives about to spawn, enemies missing, and the next item to buy with the gold still missing for it.

After the game

Learn from every match

A review of the game (deaths, CS, objectives) with a grade that measures how well you played against your lane opponent, and one focus for the next match. Your profile tracks your form, matches and recurring mistakes over time.

Under the hood

Riot Games API usage

Riot API

  • league-v4, match-v5: sample ranked solo games from the ladder to compute champion, matchup, item and spell winrates.
  • champion-mastery-v4: focus sampling on the champions the user plays.
  • account-v1: resolve the user's own Riot ID.

Local and static data

  • The local League client (LCU) is read only for the user's own session.
  • The Live Client Data API (localhost) only during the user's own game.
  • Data Dragon for champions, items, runes and spells; CommunityDragon for stat shard texts. No API key is used for these.

Privacy

Only aggregated statistics are stored. No personal data of other players is kept or shown. The user's own match history stays on their computer.
